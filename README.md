# GothParadise Shop

A gothic-themed online shop demo, built as a learning project with Python, with a Tkinter desktop version and soon a Flask web version.

Browse a small catalog, add items to the cart, watch the total update, and
go through a simple checkout.

## Features
- Product cards with images, descriptions and prices
- Shopping cart with a live-updating total
- Checkout with email validation
- Custom themed interface (colors, frame, fonts)

## Built with
- Python 3
- Tkinter and Pillow (desktop version)
- Flask, HTML and CSS (web version)

## Note
This is a fictional shop made for educational purposes. No real products
are sold and no payments are processed.
